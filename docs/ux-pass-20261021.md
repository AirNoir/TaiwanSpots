# UX / UI 優化（2026-10-21 下午）

使用者要求：地圖只有「無數個點」，沒有目標感，也看不到名稱；整體做 UI 美化、UX 優化和修 bug。以下是做了什麼、怎麼驗證、接下來可以做什麼。

## 地圖（`src/components/TaiwanWorld.tsx`）

三層，加上一層縣市：

| 層級 | 看到什麼 | 點了會怎樣 |
|---|---|---|
| 全島 | 地標 token（有圖的 anchor）、每個**縣市一盞燈**（大小隨收藏數變大，取代原本 130 個點）、未收藏 anchor 小點、**「下一站」旗子**（離你最近的未收藏景點，附距離） | 點區域：放大到區域。點旗子：直接放大到該縣市，並選取那個景點 |
| 區域 | 景點多的縣市（≥2 個）收成一顆**縣市泡泡**：代表景點縮圖、總數徽章、「台北 5/14」；單一景點的縣市直接顯示縮圖 pin | 點泡泡：打開該縣市 |
| 縣市 | 只顯示該縣市的景點，每個是**圓形縮圖 pin**（未收藏的會淡化），名稱標籤依序試下、右、左、上四個位置，避開重疊；離你最近的未收藏景點外圈會脈動。地形會淡化成背景，因為放大後地形沒有細節 | 第一下：浮出**說明卡**（縮圖、名稱、城市、距離、收藏狀態）。第二下或點卡片：進入景點頁 |

- 地圖下方的**景點輪播**列出目前範圍的所有景點，未收藏的排前面並依距離排序。點卡片會在地圖上選取該景點；如果它在還沒打開的縣市裡，會先打開縣市。
- 返回鍵：縣市 → 區域 → 全島。
- 夜晚：地圖變成深藍夜空面板加星星，只有島嶼本身變暗（用群組透明度，陸地和底座重疊處不會暗兩次），光點和地標在上層。以前是一整塊灰色長方形。
- 選取 pin 或卡片時有輕微震動（`expo-haptics`）。

## 其他畫面

- **首頁**：「NEXT STOP」主卡（全彩縮圖、距離、看看／導航）；抵達範圍時改成強調色，按鈕變「去收藏」。其餘附近景點顯示「可收藏」徽章。
- **Explore**：搜尋（名稱、英文名、城市），「全部／未收藏／已收藏」篩選，顯示結果數量和空狀態。
- **護照**：未收藏的格子也顯示名稱（以前是 ????）；點上方的區域數字可以只看該區域。
- **景點頁**：底部「順路還有」，列出最近 4 個、30 km 內的景點；英文名不再隱藏；標籤可換行。
- **收藏動畫**：背景改成不透明（底下的頁面不再透出），加上「第 N 個景點 · 南投 1/11」進度；集滿縣市會顯示「全收齊！」。
- **成就**：新增中、南、東台灣全收。「TAIWAN MASTER」的說明改成「收藏全部景點」。

| 沒有定位權限時，以台北車站為準顯示假距離，**台北車站 1 km 內的景點甚至能直接收藏** | 改用替代位置時一律判定不在範圍內（景點頁、Explore、首頁）；距離改顯示「開啟定位，才能知道你離這裡多遠」；地圖用 `approximate` 隱藏距離，但仍會標出下一站 |
| 輪播在每次 GPS 更新時重新排序並捲回去 | 距離以 100 m 為單位排序、只在選取改變時捲動，並等版面配置完成後再捲 |
| 點「下一站」旗子時，只有一個景點的縣市會放大到 12.8 倍 | 只有被收成泡泡的縣市才會打開 |
| 讀螢幕功能：首頁下一站卡片裡的導航按鈕讀不到；返回鍵和區域 chip 沒有標籤 | 補上 role 與 label，區域 chip 帶選取狀態 |
| GPS 監聽在快速關閉頁面時沒被移除 | `useLocation` 在 watch 建好後檢查 `mounted` |
| 離線時用了好幾小時前的天氣，中午顯示成夜晚 | `useWeather` 不回傳超過 3 小時的資料 |
| 收藏日期用 UTC，台灣早上 8 點前會顯示成前一天 | 改用本地日期 |
| 分享失敗沒有任何提示 | 加錯誤提示 |

## 開發自動化（只在 `__DEV__`）

除了原有的 `__islandia`（store）和 `__islandiaRouter`：

- `__islandiaMap.region('north' | null)`、`.county('台北' | null)`、`.select(spotId | null)`
- `__islandiaScroll.home(y)`、`__islandiaScroll.spot(y)`
- `__islandiaUnlock()`：在景點頁直接播放收藏動畫（不會檢查距離；按「加入收藏」才會真的收藏）

用法見 `docs/radius-navigation-weather.md` 的 CDP 段落。模擬器的 Expo Go 若被升到 SDK 58，從 `https://api.expo.dev/v2/versions/latest` 的 `sdkVersions["57.0.0"].iosClientUrl` 下載 57 版重裝。

## 驗證

- 每次 commit 前都跑 `npx tsc --noEmit` 和 `npx expo lint`，全部通過。
- 用 iPhone 16 Pro 模擬器（Expo Go 57.0.9）截圖確認：全島日／夜、北部縣市泡泡、台北和南投的縣市層、說明卡、輪播、0 收藏的新使用者、深色模式、收藏動畫、護照、Explore、景點頁。
- 還沒在實機上測：震動、導航按鈕、定位權限被拒絕的情況。
