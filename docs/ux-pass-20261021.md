# UX / UI 優化（2026-10-21 下午）

使用者要求：地圖只有「無數個點」，沒有目標感，也看不到名稱；整體做 UI 美化、UX 優化和修 bug。以下是做了什麼、怎麼驗證、接下來可以做什麼。

## 地圖（`src/components/TaiwanWorld.tsx`）

三層，加上一層縣市：

| 層級 | 看到什麼 | 點了會怎樣 |
|---|---|---|
| 全島 | 地標 token（有圖的 anchor）、每個**縣市一盞燈**（大小隨收藏數變大，取代原本 130 個點）、未收藏 anchor 小點、**「下一站」旗子**（離你最近的未收藏景點，附距離） | 點區域：放大到區域。點縣市燈：直接打開該縣市。點旗子：打開該縣市，並選取那個景點 |
| 區域 | 景點多的縣市（≥2 個）收成一顆**縣市泡泡**：代表景點縮圖、總數徽章、「台北 5/14」；單一景點的縣市直接顯示縮圖 pin | 點泡泡：打開該縣市 |
| 縣市 | 只顯示該縣市的景點，每個是**圓形縮圖 pin**（未收藏的會淡化），名稱標籤依序試下、右、左、上四個位置，避開重疊；離你最近的未收藏景點外圈會脈動。地形會淡化成背景，因為放大後地形沒有細節 | 第一下：浮出**說明卡**（縮圖、名稱、城市、距離、收藏狀態）。第二下或點卡片：進入景點頁 |

- 地圖下方的**景點輪播**列出目前範圍的所有景點，未收藏的排前面並依距離排序。點卡片會在地圖上選取該景點；如果它在還沒打開的縣市裡，會先打開縣市。
- 返回鍵：縣市 → 區域 → 全島。
- 夜晚：地圖變成深藍夜空面板加星星，只有島嶼本身變暗（用群組透明度，陸地和底座重疊處不會暗兩次），光點和地標在上層。以前是一整塊灰色長方形。
- 選取 pin 或卡片時有輕微震動（`expo-haptics`）。

### 真實地圖（2026-10-21 晚，`src/components/RealMap.tsx`）

使用者回饋：區域和縣市層是「綠綠一塊，幾個圓點」。現在**點區域之後換成真實地圖**（`react-native-maps`：iOS 用 Apple 地圖，Android 用 Google 地圖）：

- 區域：真實地圖加上縣市泡泡（中心太近的會在螢幕上推開，例如台北、新北、基隆），只有一個景點的縣市直接顯示縮圖 pin。
- 縣市：自動縮放到該縣市的所有景點，看得到鄉鎮區名、道路和河流；可以雙指縮放和拖曳。名稱標籤依目前鏡頭計算，放大後顯示更多，而且不會重疊。
- 說明卡固定在地圖底部；從輪播選景點時，地圖會移到該景點。
- 地圖樣式用 `mutedStandard`，關掉 POI、建築和指南針；深色主題或夜晚時用深色地圖；有定位時顯示藍點。
- 全島那一層維持微縮台灣，因為那是這個 App 的招牌畫面。
- **Android 正式版**需要 Google Maps API key（`app.json` 的 `android.config.googleMaps.apiKey`，見 Expo 的 react-native-maps 文件）；Expo Go 和 iOS 不需要。

## 其他畫面

- **首頁**：「NEXT STOP」主卡（全彩縮圖、距離、看看／導航）；抵達範圍時改成強調色，按鈕變「去收藏」。其餘附近景點顯示「可收藏」徽章。
- **Explore**：搜尋（名稱、英文名、城市），「全部／未收藏／已收藏」篩選，顯示結果數量和空狀態。
- **護照**：未收藏的格子也顯示名稱（以前是 ????）；點上方的區域數字可以只看該區域。
- **景點頁**：底部「順路還有」，列出最近 4 個、30 km 內的景點；英文名不再隱藏；標籤可換行。
- **收藏動畫**：背景改成不透明（底下的頁面不再透出），加上「第 N 個景點 · 南投 1/11」進度；集滿縣市會顯示「全收齊！」。
- **成就**：新增中、南、東台灣全收。「TAIWAN MASTER」的說明改成「收藏全部景點」。

## 收集狂視角（2026-10-22）

使用者回饋：「我在地圖上看不到一些我沒去過的點，也沒有提示，也沒有名稱」。

- 全島：每個縣市一個標記。有收藏的縣市發光，旁邊的數字是**還沒收藏**的景點數；完全沒去過的縣市是空心圈。
- 區域：縣市泡泡右上角改成「還差幾個」，收齊了變成勾勾；未收齊的泡泡是橘框。
- 縣市（真實地圖）：
  - 未收藏的 pin 是橘框，已收藏的是白框加勾勾。
  - 名稱優先給「下一站」，其次是未收藏的景點；標籤會放在 pin 的上、下、左或右。
  - 擠在一起的 pin（萬華、中正）在螢幕上推開，放大後回到原位。
- 「只看未收藏」開關：在返回鍵下方，地圖和輪播都只留還沒收藏的。

技術備註：iOS 的 Apple Maps 只用第一次排版的大小來置中自訂 marker。所以名稱標籤做成獨立的 marker，pin 的大小固定；被選取而變大的 pin 用 key 重新掛載。dashed 邊框在 iOS 會被圓形縮圖蓋住，所以不使用。

## 開發自動化（只在 `__DEV__`）

除了原有的 `__islandia`（store）和 `__islandiaRouter`：

- `__islandiaMap.region('north' | null)`、`.county('台北' | null)`、`.select(spotId | null)`、`.todoOnly(true | false)`
- `__islandiaScroll.home(y)`、`__islandiaScroll.spot(y)`
- `__islandiaUnlock()`：在景點頁直接播放收藏動畫（不會檢查距離；按「加入收藏」才會真的收藏）

用法見 `docs/radius-navigation-weather.md` 的 CDP 段落。模擬器的 Expo Go 若被升到 SDK 58，從 `https://api.expo.dev/v2/versions/latest` 的 `sdkVersions["57.0.0"].iosClientUrl` 下載 57 版重裝。
