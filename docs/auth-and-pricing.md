# 登入與買斷制規劃（2026-10-22，尚未實作）

> 定稿版規格見 `docs/spec.md`；本文件保留當初的討論。

## 一、登入：Google、Apple、訪客

### 先釐清登入要解決什麼

目前收藏紀錄只存在手機上，不需要帳號。買斷制本身也**不需要登入**：Apple 的購買綁在 Apple ID 上，換手機時按「恢復購買」就能拿回來。

登入真正的價值是**雲端備份與跨裝置同步**（換手機、iPhone 和 iPad 同時用、之後出 Android）。之後若要做排行榜或好友，也需要帳號。

### 建議流程

1. 第一次打開 App 直接以**訪客**身分開始，不擋登入畫面。收藏照樣存在手機上，和現在一樣。
2. 在「我的」頁放「備份我的收藏」，可以選 Google 或 Apple 登入。登入後，手機上的紀錄合併到雲端帳號。
3. 換手機時，先登入同一個帳號，收藏就會回來。

「匿名登入」在技術上就是第 1 步：後台先建一個沒有 email 的匿名帳號，之後再把 Google 或 Apple 綁上去，同一份資料不會遺失。

### App Store 規定（一定要做）

- **有 Google 登入就必須同時提供「使用 Apple 登入」**（審核準則 4.8）。
- **能建立帳號就必須能在 App 內刪除帳號**（準則 5.1.1(v)）。
- 隱私權政策（`docs/privacy.md`）和 App Store 隱私標籤要改：目前寫的是「不建立帳號、不上傳資料」。

### 技術選擇（建議 Supabase）

| 項目 | 選擇 |
|---|---|
| 帳號與資料庫 | Supabase：支援匿名登入、之後綁定 Google／Apple（linkIdentity）、Postgres 加列級權限（RLS）。免費方案足夠起步 |
| Google 登入 | `@react-native-google-signin/google-signin`（Expo 文件推薦，原生按鈕）取得 ID token，交給 Supabase `signInWithIdToken` |
| Apple 登入 | `expo-apple-authentication`，同樣用 `signInWithIdToken` |
| 同步 | 每筆收藏一列（spot_id、時間、季節、天氣），以「先到先贏」合併，不會互相覆蓋 |

替代方案：Firebase（Auth + Firestore）也可以，但原生套件比較重。

### 對開發流程的影響

這些套件都含原生程式碼，**不能在 Expo Go 跑**，要改用 development build。本機 Xcode 16.2 編不了（expo-widgets 需要 26.4 以上），所以 development build 也要走 EAS 雲端，大約 15 分鐘一次。

### 需要你準備的

- Google Cloud 專案：iOS OAuth Client ID（以及之後 Android 用的）。
- Supabase 專案（或授權我用 EAS 的 Supabase 整合建立）。
- 在 Apple Developer 後台為 `com.airnoir.islandia` 開啟 Sign in with Apple。

## 二、買斷制與免費體驗

### 原則

- **永遠不擋打卡**。收藏狂最怕的是「人到了卻記不下來」。免費版走到哪都能打卡，紀錄一定留著。
- **探索免費、模型付費**。地圖、130 個景點的名稱和位置、距離、導航、天氣全部免費，這些會吸引人出門。付費買的是「看得到、留得住的微縮模型」。
- 付費的那一刻，之前所有封存的收藏**一次全部解鎖**，那是最爽的瞬間。

### 免費版

| 功能 | 免費 |
|---|---|
| 全島、區域、真實地圖，所有景點名稱與未收藏提示 | ✅ |
| 打卡（不限次數）＋護照印章與日期 | ✅ |
| 微縮模型 | **前 10 個**完整解鎖（含收藏動畫、全螢幕檢視、分享卡） |
| 第 11 個起 | 照樣打卡、播動畫，但模型是「封存」狀態（剪影＋印章），購買後全部開箱 |
| 成就 | 基本成就（第一步、城市漫遊等） |
| 導航、天氣、季節 | ✅ |

為什麼是 10 個：北部使用者一個週末就走得到（台北市就有 14 個），能體驗 10 次「開箱」的快感，付費牆剛好出現在興頭上。

不建議的做法：
- **只開放某個區域**：住南部或東部的人一開始就吃虧。
- **限時 7 天**：旅行是斷斷續續的，常常隔幾個月才出門一次。

### 完整版（一次買斷）

- 本島全部 130 個模型，以及之後新增的本島景點
- 完整成就（北中南東制霸、台灣全制霸、四季旅人）
- 主畫面 Widget、走近景點的動態島（也可以留在免費版當宣傳，待決定）
- 之後的季節／夜晚版本模型

外島禮包（`docs/dlc-outer-islands.md`）另外加價購買，不包含在完整版裡。

### 價格建議

- 完整版：NT$150–190（Apple 價格等級），上架首月可以打折。
- 外島禮包：NT$90–150。
- 兩個都是「非消耗性項目」（non-consumable），App 內一定要有「恢復購買」按鈕。

### 付費實作

建議 RevenueCat（`react-native-purchases`，Expo 文件推薦）：它幫忙驗證收據、管理權益（entitlement）、處理恢復購買，之後上 Android 也通用，營收在一定額度內免費。若完全不想用第三方，可改用 `expo-iap`，權益存在手機上。

權益和登入是分開的：沒登入也能買、能恢復購買；有登入時把權益一起同步。

## 三、建議順序

1. **買斷制＋免費 10 個**（不需要後台）：付費牆、封存狀態、恢復購買、商品設定。
2. **登入與雲端備份**：訪客 → Google／Apple 綁定、同步、刪除帳號、隱私權政策更新。
3. 外島禮包。

## 待你決定

1. 免費解鎖幾個模型（建議 10 個）。
2. 完整版價格。
3. Widget 和動態島要放在免費版還是付費版。
4. 登入後台用 Supabase 還是 Firebase；要不要先只做買斷、晚點再做登入。
