製作說明與參考

整個場景由一支 Blender Python 腳本程序生成：地形板塊、六顆超橢球加噪聲位移的砂岩、沿步道高度剖面鋪的石階、木欄杆、Q 版登山客，以及旋轉 28° 的街廓網格（人行道、雙黃線、斑馬線、右側通行的車流、路邊機車、行道樹）。台北 101 有 25 層底座、八段外擴塔身、如意飾與尖塔；南山廣場為切角塔身與分段冠部。

主視角圖以 Cycles 路徑追蹤渲染；這個網頁載入的是同一個場景匯出的 glTF，岩石與地形的顏色和法線已烘焙成貼圖，其餘為平面材質。車流在瀏覽器端沿各自車道前進。
