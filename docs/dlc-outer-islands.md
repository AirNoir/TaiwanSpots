# DLC 構想：外島禮包（加價購）

2026-10-21 記下的產品構想，**還沒有實作**。先把範圍、體驗和技術路線定下來，之後要做時從「實作順序」開始。

## 一句話

本島 130 個景點免費。「外島禮包」是一次性買斷的加價購，打開一張新的海上地圖：澎湖、金門、馬祖，加上目前還沒上架的綠島和蘭嶼。

## 範圍

| 群島 | 建議景點（約 20–24 個） | 備註 |
|---|---|---|
| 澎湖 | 雙心石滬、跨海大橋、七美、望安、吉貝沙尾、玄武岩（大菓葉）、天后宮、馬公老街 | 夏季花火節可做季節限定變體 |
| 金門 | 莒光樓、翟山坑道、水頭聚落、八二三戰史館、獅山砲陣地、慈湖 | |
| 馬祖 | 芹壁聚落、藍眼淚（北竿）、大坵梅花鹿、八八坑道、東引燈塔 | 藍眼淚只有晚上才收得到，正好用上日夜系統 |
| 綠島、蘭嶼 | 已有資料（`green-island`、`lanyu`），目前 `active: false`，圖還沒做 | 從沒上架過，放進 DLC 不算把免費內容收回 |

**原則**：已經免費上架的景點（例如小琉球）永遠不搬進 DLC。

## 體驗

- **入口**：台灣大地圖右下角海上出現一個「外島」浮標（未購買時是半透明剪影）。點下去切換到外島地圖；沒買的話先顯示禮包介紹頁。
- **介紹頁**：外島地圖全景，加上 3 張代表景點的縮圖（雙心石滬、莒光樓、藍眼淚），寫清楚價格和「一次買斷，之後新增的外島景點都包含」。
- **地圖**：一個新的 `WorldDef`（`id: 'outer-islands'`），用現有的 `TaiwanWorld` 元件就能畫，因為它本來就吃 `world` prop。澎湖在左、金門和馬祖在左上，各自是一組小島。縣市泡泡、縮圖 pin 和輪播都能直接沿用。
- **收藏**：規則和本島一樣，要進入 1 km 才能收藏，所以禮包買的是「可以收藏的資格」，還是要真的去。
- **護照**：多一頁「OUTER ISLANDS」，有自己的進度。本島的「130 / 130」不受影響。
- **成就**：「三島旅人」（澎金馬各收 1 個）、「藍色的眼淚」（晚上在馬祖收藏）。

## 定價建議

- 台灣地區 App Store 價格等級 NT$90–150，一次買斷（non-consumable）。
- 不做訂閱，因為旅遊收藏是低頻行為，訂閱會讓人覺得在收過路費。
- 可以考慮「到過外島就送」的彩蛋：在澎金馬實際打開 App 時跳出折扣，但這要先確認 App Store 規範。

## 技術路線（之後實作時）

1. **資料**：`Spot.worldId = 'outer-islands'`，新增 `Spot.pack?: 'outer-islands'`。`SPOTS` 繼續包含它們，再用 `isUnlocked(spot)` 判斷能不能收藏，這樣 Explore 和地圖才看得到未購買的外島景點（作為誘因）。
2. **購買**：IAP 套件（候選 `expo-iap` 或 `react-native-iap`）實作前先查 SDK 57 版的 Expo 文件，確認目前推薦哪一個（不要憑印象選）。這需要 development build，Expo Go 不能用。商品 ID 定為 `com.airnoir.islandia.pack.outer_islands`。
3. **權益**：購買成功後寫進 store（`ownedPacks: string[]`），每次啟動用 `getAvailablePurchases` 回補，「恢復購買」按鈕放在 ME 頁。不需要自己的伺服器。
4. **圖片**：外島圖片約 24 × 0.3 MB ≈ 7 MB。可以直接打包，或等購買後再下載（`expo-file-system`）。數量不多，建議先直接打包，比較簡單。
5. **地圖**：`TaiwanWorld` 已經支援 `world` prop，要補的是外島的 `WorldDef`（海岸線、島群座標）和「切換世界」的入口。
6. **審核**：App Store 規定要有恢復購買的入口；介紹頁要清楚標示價格與內容。

## 實作順序

1. 先做外島的美術（沿用 `docs/art-pipeline.md`），至少每個群島 3 張，介紹頁才有東西可放。
2. 資料與 `WorldDef`。這一步完成後，開發版就能開外島地圖（先不鎖）。
3. IAP 套件加上購買、恢復購買與鎖定 UI。
4. App Store Connect 建立商品、送審。

## 還沒決定

- 是否把綠島、蘭嶼放進 DLC（目前的建議是放，因為它們從沒上架過）。
